# مراجعة مع المدربة

جاوب أولاً، بعدين افتح الإجابات. حاول تربط كل جواب بملف فعلي من الأمثلة.

1. شو الفرق بين class وobject؟ وليش self؟
2. هل __init__ هو الذي ينشئ الكائن فعلياً؟
3. شو الفرق بين class attribute وinstance attribute؟ أعطِ فخ mutable list.
4. هل _name و__name private فعلياً؟
5. متى تستخدم property؟
6. شو الفرق بين encapsulation وabstraction؟
7. هل polymorphism يحتاج inheritance؟
8. شو فائدة super؟ وما علاقته بـ MRO؟
9. متى تختار composition؟
10. فرّق بين instance/class/static method.
11. شو الفرق بين ABC وProtocol؟ وهل annotations تتحقق وقت التشغيل؟
12. شو يولد dataclass؟ وهل frozen يجمّد قائمة داخل الكائن؟
13. هل SRP يعني method واحدة؟
14. كيف تضيف خصماً وتحقق OCP؟
15. أعطِ خرق LSP وفسّر العقد المكسور.
16. شو الفرق بين SRP وISP؟
17. فرّق بين DIP وDependency Injection.
18. ليش RatingService ترجع None عند عدم وجود تقييمات؟
19. كيف تمنع إضافة تقييم لكتاب غير موجود؟
20. لو بدّلنا التخزين إلى SQLite، أي أجزاء تحتاج تغيير؟

1. الكلاس تعريف والـ object نسخة؛ self يشير للنسخة الحالية.
2. __new__ ينشئ، __init__ يهيّئ.
3. متغير الكلاس مشترك؛ متغير النسخة مستقل. القائمة على الكلاس قد تتغير للجميع.
4. الأول convention والثاني name mangling، مش حماية أمنية.
5. قراءة محسوبة أو وصول منظم مع تحقق، مثل balance.
6. التغليف ينظم الحالة والوصول؛ التجريد يعرض العقد ويخفي التفاصيل.
7. لا؛ duck typing يسمح بسلوك مشترك بدون أب واحد.
8. يستدعي التنفيذ التالي حسب MRO ويدعم cooperative inheritance.
9. لما كائن يحتاج سلوكاً من كائن آخر بدون علاقة is-a صحيحة.
10. الأولى self، الثانية cls، الثالثة لا تحتاج أياً منهما.
11. ABC يوفر عقداً اسمياً ويمكن منع إنشاء subclass ناقص؛ Protocol يدعم structural typing. لا تحقق آلي للـ hints.
12. يولد init/repr/eq افتراضياً؛ frozen لا يجمّد العناصر الداخلية المتغيرة.
13. لا؛ سبب متماسك للتغيير وقد يتطلب عدة methods.
14. implementation جديد لعقد Discount، مع إبقاء checkout كما هي.
15. بطريق يرث عقد fly ثم يفشل؛ الأساسي وعد بالطيران لكل بديل.
16. SRP أسباب تغيير الوحدة، ISP حجم العقد من منظور المستهلك.
17. DIP اتجاه الاعتماد نحو التجريد؛ DI تمرير الاعتماد من الخارج.
18. لتمييز عدم وجود بيانات عن تقييم رقمي؛ الصفر خارج نطاق التقييم هنا.
19. خدمة المراجعات تتحقق قبل الكتابة وترمي LookupError بدون تغيير الحالة.
20. أضف adapter يحقق العقود، اختبره، وعدّل wiring؛ تبقى الخدمات كما هي إن حُفظ العقد.
