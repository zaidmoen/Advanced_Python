# الحلول

من جذر الريبو:

```bash
python -m solutions.cart
python -m solutions.notifications
python -m solutions.discount
python -m solutions.policy_service
```

1. السلة تخزّن قائمة لكل نسخة، تتحقق قبل الإضافة، وتحسب total من الحالة الداخلية.
2. notify تعتمد على send فقط؛ الكلاسات لا تحتاج أباً مشتركاً.
3. سياسة جديدة بدون تعديل المستهلك.
4. تحقق النطاق الأساسي يبقى في Review، والسياسة الإضافية تُحقن في الخدمة.

إجابات التتبّع: قائمة الكلاس مشتركة؛ إرجاع القائمة الداخلية يسمح بمسحها أو الإضافة عليها؛ إنشاء dependency داخلياً يربط الاختبار بالتنفيذ؛ type hints لا تفرض التحقق وقت التشغيل.
